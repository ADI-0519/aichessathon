# Rejected evaluation scaffold

This directory is retained to preserve the first pipeline experiment. It is
not a strength candidate: `weights.py` came from only 50 shallow opening
positions, had no validation split, and is deliberately not connected to the
search evaluator.

Do not submit or arena-test this directory as V4. It currently behaves like
V3. New evaluation candidates must be generated through
`docs/EVALUATION_TUNING.md` and placed in a newly named challenger directory
after offline/runtime feature parity has been tested.
