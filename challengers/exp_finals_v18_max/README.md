# Finals V18 maximum-change candidate

This is the deliberate high-variance bundle for short-control screening. It
combines:

- the continuous long-horizon clock;
- deferred move generation;
- SearchMax LMR and shallow-pruning depths; and
- the 50% BigNet blend favoured by held-out RMSE.

Every component exists in a narrower challenger. This directory answers whether
their interaction produces a large practical gain quickly; it is not eligible
for promotion merely because its components are individually plausible.
